Security, must-have:
- Tenant isolation: every API route gets guildId ONLY from the verified session cookie, never from the body, query or URL. Namespace Redis keys per guild.
- Writes: check the Origin header and require JSON content-type. Reject bodies over 8KB.
- Headers on every response: CSP, nosniff, Referrer-Policy no-referrer, frame-ancestors 'none'.
- Keep the existing server-side validation and HTML escaping. Race/class validation must use the guild's faction.

- reads: 300 per minute per IP
